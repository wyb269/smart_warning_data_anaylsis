# 防返贫数据展示与智能预警平台

> **项目状态说明**：本仓库是一份基于现有 PRD 与 Pencil 原型撰写的「项目完成态推演」。文档中的数据仓、加工任务、应用服务和验收结果是**假设项目已完成时的参考实施叙述**，不是当前实际部署或验收证明。仓库唯一的实际产品产物是合成数据绘制的 `.pen` 原型。

## 项目目标

让授权工作人员先看清人员整合数据，再看到规则自动计算的预警及依据，减少逐人查找、比对和初筛的时间。平台不负责逐人分派、办理状态或人工判断，也不把自动预警等同于正式的防返贫认定。

## 完成态技术路径（推演）

```mermaid
flowchart LR
    A[外部授权数据] --> B[公司集中数据仓 / Hive 源表]
    B --> C[人员匹配、标准化、质量检查]
    C --> D[整合人员表与指标结果表]
    D --> E[经确认规则自动计算]
    E --> F[人员、预警、总览、来源状态报表]
    F --> G[授权查询服务]
    G --> H[数据展示平台]
```

源表保留以供追溯，报表是从源表加工出的派生结果，并不覆盖源表。假设公司提供集中式 Hive 服务和授权访问；本机 Docker Hive 只是学习环境，不属于这条生产数据链路。技术选型和权限范围在真实项目中必须由公司确认。

## 核心设计原则

1. **数据展示优先**：人员清单可筛选省、市、县、乡、村，详情逐项展示《整合表》B–V 的必要字段。
2. **预警由规则产生**：仅启用有数据来源且规则已确认的指标，展示具体值、来源、时间和规则版本。
3. **缺失不是未命中**：分别标明已命中、确认未命中、无法判断、未接入；统计不把后两者算作无风险。
4. **权限与脱敏**：仅向授权人员展示最小必要字段，证件号默认脱敏，个人详情访问留痕。

仓库名 `smart_warning_data_anaylsis` 按提出时的拼写保留。
